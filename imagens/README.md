# Imagens do projeto

Adicione aqui, após a montagem, imagens de:

1. Visão geral da protoboard do transmissor e receptor.
2. Detalhe dos pinos ligados ao ESP32.
3. LED apontado para o LDR.
4. Monitor Serial com transmissão e recepção.

Use nomes simples, por exemplo `montagem-geral.jpg`, `led-ldr.jpg`, `monitor-serial.png`.

**Privacidade:** confira o enquadramento antes de publicar fotografias no GitHub. Não é necessário subir todas as fotos pessoais originais.
