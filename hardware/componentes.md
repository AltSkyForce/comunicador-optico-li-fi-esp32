# Lista de materiais

| Item | Quantidade | Observação |
|---|---:|---|
| ESP32 DevKit (38 pinos) | 1 | Confirmado por foto da placa preta |
| Protoboard | 2 | Confirmadas por foto |
| Jumper | Vários | Confirmados por foto |
| LED visível | 1 (há 2) | Confirmado por foto; cor/especificação a testar |
| LDR | 1 (há 2) | Confirmados por foto |
| Resistor LED | 1 | **Confirmar 220 Ω ou 330 Ω** antes de usar |
| Resistor do LDR | 1 | **Confirmar 10 kΩ** antes de usar |
| Cabo USB de dados | 1 | Verificar: carregar não garante transmitir dados |
| Tubo de papelão | Opcional | Ajuda a bloquear iluminação externa |
| CD velho | Opcional | Não é requisito para transmissão direta |

**Nota:** a plaquinha vermelha fotografada parece um adaptador USB–serial (FT232 ou similar), não um microcontrolador. Não é necessária.

## Como reconhecer resistores

Leia as faixas de cores ou use multímetro; o aspecto na fotografia não é suficiente para confirmar valores com segurança. **Nunca ligue LED diretamente ao GPIO**.
